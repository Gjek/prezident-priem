# ПрезиДЕНТ — лендинг записи на приём

Один самодостаточный файл `index.html`: стили, скрипты, шрифты и фото встроены внутрь, сборка не нужна.

## Как использовать
- Открыть страницу: https://gjek.github.io/prezident-priem/
- Вставить в Tilda: скопировать содержимое `index.html` в блок T123 (HTML-код).
